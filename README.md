# Zudin987 Tools

Simple static website for the public Zudin987 BPSR, MIDI, and streaming tools.

Live site: **https://zudin987.github.io/**

## Pages

- `/` — project list.
- `/projects/bpsr-midi/` — BPSR MIDI Lite / Studio.
- `/projects/bluemeter/` — BlueMeter Lite and APK picker.
- `/projects/custompfp/` — CustomPFP Lite with safety warning.
- `/projects/readyalert/` — BPSR Ready Alert.
- `/projects/streamkit/` — Portable Stream Kit.

## UI rules

- Keep layouts simple and readable.
- Use normal text weight by default.
- Use one main content width and let controls wrap on small screens.
- Keep warnings visible only when they matter.
- Put the main download near the top of each tool page.
- No framework, analytics, ads, cookies, account system, external font, or build step.

GitHub Pages publishes the root of `main` after the normal branch → pull request → merge workflow.
