# Zudin987 Tools

Personal GitHub Pages hub for my public gaming, MIDI, and streaming utilities.

Live site: **https://zudin987.github.io/**

## Design goals

- Beginner-first wording and obvious download paths.
- Fast static HTML/CSS/JS with no framework or build step.
- Mobile-friendly and keyboard-accessible.
- No analytics, ads, cookies, database, or account system.
- Project downloads always point back to the matching GitHub repository/release page.

## Files

- `index.html` — project hub and beginner download guide.
- `styles.css` — responsive site styling.
- `script.js` — tiny mobile-navigation/year helper only.
- `favicon.svg` — site icon.
- `404.html` — friendly missing-page fallback.

GitHub Pages can publish this repository directly from the root of the `main` branch.
