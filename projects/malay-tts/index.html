Malay TTS Bot

A self-hosted Discord text-to-speech bot for Malaysian Malay and Malaysian English. Runs on Windows with Gemini speech and a Google fallback, without a local AI model.

Download latest release Read documentation
View source on GitHubReport an issue

What it does

  • Speaks eligible chat messages and announces the sender separately.
  • Voice selection, pronunciation controls and per-user text-to-speech opt-out.
  • A separate /ask command for short AI answers, plus status and privacy commands.

Quick start

  1. Download the CLEAN ZIP and extract it into an empty C:\Malay-TTS-Bot folder.
  2. Follow the README to configure your Discord bot and .env credentials. For an upgrade, restore only .env and data\guilds.json.
  3. Run setup-clean.cmd as administrator, then start the Malay TTS Bot task. Join a voice channel and use /join.

  • Maintenance and troubleshooting

Requirements

  • Windows 11 PC that stays on while the bot runs
  • Your own Discord bot with Message Content Intent
  • Gemini API key for Gemini speech and /ask
  • Administrator access for Task Scheduler setup

Before you use it

Setup registers a Windows SYSTEM task. Keep .env private and follow the README’s clean-install instructions.

Eligible message text is sent to speech providers, and sender names go to Google. Use /ttsprivacy for details and /ttsoptout for normal-chat opt-out.
