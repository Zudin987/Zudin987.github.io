BlueMeter Lite

An Android combat meter for Blue Protocol: Star Resonance. Keep combat statistics over the game without a PC.

Download latest release Read documentation
View source on GitHubView pull requests

What it does

  • DPS, healing and damage-received statistics with compact and expanded overlay modes.
  • Movable, resizable rankings with local-player highlighting and encounter history.
  • Processes supported BPSR traffic locally on your Android device.

Quick start

  1. Download and install the APK from Releases. Choose arm64-v8a for most modern Android phones.
  2. Open BlueMeter Lite, allow Display over other apps, then tap Start DPS Meter and approve the VPN prompt.
  3. Open BPSR and enter combat. Move or resize the overlay to suit your screen.

Requirements

  • Android with a supported BPSR client
  • Permission to display over other apps
  • Android’s local VPN permission

Before you use it

Uses Android’s VPN slot for local capture, so another VPN cannot run at the same time. This is not a remote VPN service.

Combat data stays on your device. Protocol updates may require a new app version.

Issue tracking is disabled for this repository. Proposed fixes can be submitted through GitHub pull requests.
