BlueMeter Lite

An Android combat meter for Blue Protocol: Star Resonance. Keep combat statistics over the game without a PC.

Download Android (ARM64) · ReleasesOther APK versions
Read documentationView source on GitHub

What it does

  • DPS, healing and damage-received statistics with compact and expanded overlays.
  • Movable, resizable rankings with local-player highlighting and encounter history.
  • Processes supported BPSR network traffic locally on your Android device.

Quick start

  1. Download the APK from Releases. Select arm64-v8a for most modern Android phones; use Other APK versions if your device requires a different architecture.
  2. Install and open BlueMeter Lite, allow Display over other apps, then tap Start DPS Meter and approve Android's VPN prompt.
  3. Open BPSR and enter combat. Move or resize the overlay to suit your screen.

Further reading

Requirements

  • Android with a supported BPSR client
  • Permission to display over other apps
  • Android local VPN permission

Before you use it

Uses Android's VPN slot for local capture, so another VPN cannot run at the same time. This is not a remote VPN service.

Combat data stays on your device. Protocol changes can require a new app version.
