Quick start

Three steps to the overlay

  1. Install the APKUse the architecture picker on this page. Most recent Android phones use arm64-v8a.
  2. Open BlueMeter Lite and tap Start DPS MeterAllow Display over other apps and approve Android's VPN prompt.
  3. Open BPSR and start fightingThe combat meter appears over the game. Unlock it when you want to move or resize it.

What it shows

One overlay, three combat views

  • DPS meter for damage output.
  • Healing meter for healing done.
  • Tanking meter for damage received.
  • Compact and expanded layouts with remembered size and position.
  • Manual reset plus automatic encounter reset where supported.
  • Encounter history stored locally for up to seven days.

Privacy & network behavior

The VPN prompt is local

BlueMeter Lite uses Android's local VPN feature to observe supported BPSR traffic on the same device. It is not a project-operated remote VPN service.

  • No user account, advertising, analytics or project-operated combat-data server.
  • Combat information is processed locally on the Android device.
  • Supports HaoPlay SEA, A Plus Japan/Global, Taiwan/Hong Kong/Macau and X.D. regional clients.
Game or protocol updates can require a BlueMeter Lite update. If the overlay suddenly stops reading combat after a game patch, check the latest release first.
