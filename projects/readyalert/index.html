Quick start

Set it once, then leave it in the tray

  1. Make sure Npcap is installedIf Resonance Logs CN already uses Npcap, you normally do not need another installation.
  2. Open BPSR Ready AlertOn first run, select resonance-logs-cn.exe if it is not found automatically.
  3. Choose the network adapter if neededBy default it follows Resonance Logs CN's saved Npcap device or selects a likely active Ethernet/Wi-Fi adapter.
  4. Leave the app in the system trayRight-click the tray icon for Test Alert Sound, alert toggles, adapter choice, volume, logs or the Resonance Logs CN path.

What it monitors

Focused on BPSR Ready events

  • Matchmaking accept / Ready popup alerts.
  • Party Ready Check alerts.
  • Party or dungeon activity vote alerts.
  • Short duplicate suppression so one event does not repeatedly play the sound.
  • Per-alert toggles and app-local alert volume.
No game injection: Ready Alert uses Npcap packet capture. It does not inject into or modify the BPSR game process, and it does not replace Resonance Logs CN files.

Network adapter behavior

One capture adapter at a time

Ready Alert prefers Resonance Logs CN's saved Npcap device when available. Otherwise it looks for an active physical Ethernet/Wi-Fi adapter and avoids common VPN, VM and tunnel adapters.

If the automatic choice is wrong, use Network Adapter from the tray menu and choose one manually. You can switch back to Follow Resonance Logs CN / Auto later.
