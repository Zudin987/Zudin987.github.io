BPSR ReadyAlert

A lightweight Windows companion for Blue Protocol: Star Resonance. Follow your party’s combat, track the current encounter and hear when a queue is ready.

Download latest release Read documentation
View source on GitHubReport an issue

What it does

  • DPS, healing and tank meters with encounter history, exports and player inspection.
  • Live target HP and Enrage timer, dungeon mechanics, Food/Serum and Imagine tracking.
  • Ready and party alerts, plus a view-only chat overlay with optional translation and text-to-speech.

Quick start

  1. Install Npcap, then download BPSR-ReadyAlert.exe from the latest release.
  2. Run the app and open BPSR. If capture is empty, choose the correct network adapter in Settings.
  3. Enable the overlays you want. Ctrl+Shift+F10 toggles the DPS and Mechanics overlays.

Before you use it

Reads network traffic through Npcap. It does not inject into the game or automate gameplay.

Optional translation and speech use online services. Game or service updates can affect those features.
