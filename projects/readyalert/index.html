BPSR Ready Alert

Get fast Ready/queue alerts and, if you want it, a lightweight floating BPSR chat overlay with custom tabs, filters and keyword sounds.

What it does

  • Sound alert for matchmaking accept / Ready popup.
  • Party Ready Check and activity-confirm alerts.
  • Optional desktop notifications and app-local alert volume.
  • Optional floating Chat Overlay with World, Guild/Team, All and custom tabs.
  • Case-insensitive Show/Hide filters with easy OR / AND syntax and advanced regex support.
  • Up to three prioritized message-only keyword/regex sound rules with one shared chat-alert volume.

Chat Overlay highlights

  • Custom channels, minimum level filters, timestamps and compact mode.
  • Smart Scroll with a new-message indicator while reading older chat.
  • Always on Top, click-through hotkey and screen-edge collapse/expand.
  • Configurable font, channel colors, zebra rows, separators and opacity.
  • Private/Talk highlighting and optional sound.
  • Local blocked-user list, persistent settings, backup recovery and capture diagnostics.

Filter examples

  • serum | food | raid = match any of them.
  • One pattern per line is also OR.
  • boss AND hard requires both.
  • (raid|dungeon) works as normal regex.
  • Matching is case-insensitive, and short terms such as PA are allowed.
  • Invalid or pathological regex is guarded so it cannot crash or hang the overlay.

Quick start

  1. Make sure Npcap is installed.
  2. Download and open BPSR Ready Alert.
  3. Select Resonance Logs CN or the correct network adapter if automatic detection is wrong.
  4. Leave ReadyAlert running in the system tray.
  5. Enable Chat Overlay from the tray only if you want the chat feature.

Lightweight by design

  • Ready alerts and chat share the same Npcap capture and packet-processing pipeline.
  • The chat feature does not start a second independent packet capture.
  • When Chat Overlay is off, chat protobuf/UI processing is skipped.
  • Chat history stays in memory only.
  • The release is one self-contained Windows x64 EXE; no .NET installation is required.

Safety and compatibility

  • Npcap is required and is not bundled.
  • ReadyAlert can run beside Resonance Logs CN and can auto-launch it.
  • It does not inject into BPSR or replace game / Resonance Logs CN files.
  • The Chat Overlay is view-only: it cannot send chat or automate gameplay.
