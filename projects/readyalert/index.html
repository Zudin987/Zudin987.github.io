BPSR ReadyAlert

More than a DPS meter. Keep combat stats, party information, encounter mechanics, history and chat tools together in one lightweight Windows companion.

Download latest release Read documentation

Party information

See player Food and Serum activity, Imagine tiers and revive availability, including revive-penalty cases.

Mechanics

Track boss Enrage and supported encounter-specific Imagine mechanics such as TINA Basilisk and Kartgriff.

History

Archive encounters locally, open HTML reports in your browser and compare fights in Compare mode.

Chat

Translate supported non-English chat and optionally read Guild and Party chat aloud with TTS.

Why ReadyAlert?

  • Food & Serum tracking — See other players' active Food and Serum activity.
  • Revive status — Know who can and cannot be revived, including revive-penalty cases.
  • Imagine tiers without hovering — View tier information directly from the combat UI.
  • Built-in Enrage tracker — See how much time remains before the boss enrages.
  • Boss-specific Imagine mechanics — Built-in helpers for supported encounters such as TINA Basilisk and Kartgriff.
  • Browser-ready Encounter History — Open saved fights as HTML and compare encounters side by side.
  • Lightweight — Built in Rust and packaged as a small Windows companion.
  • Chat tools — Translate supported chat and optionally use Guild and Party TTS.

Combat and party tools

  • DPS, damage, healing, tank and damage-received statistics.
  • Normal, Compact, Raid and Compact Raid layouts.
  • Party Food, Serum, Imagine tier and revive information.
  • Live target and encounter tracking with boss Enrage timing.

Screenshots

Encounter History

Keep encounters in a local archive, open them as HTML in your browser and use Compare mode to review differences between fights.

Chat without losing focus

The Chat Overlay can automatically translate supported non-English messages to English. Guild and Party chat can also be sent to TTS when enabled.

Built for lightweight use

ReadyAlert is built in Rust and designed to be a small background companion while you play.

Quick start

  1. Install Npcap, then download BPSR-ReadyAlert.exe from the latest release.
  2. Run the app and open BPSR. If capture is empty, choose the correct network adapter in Settings.
  3. Enable the overlays, trackers and chat options you want. Ctrl+Shift+F10 toggles the combat and Mechanics overlays.

What it does not do

ReadyAlert reads game network traffic through Npcap. It does not inject into the game or automate gameplay.

Optional translation and speech use online providers. Game updates can affect compatibility.

Unofficial tool
