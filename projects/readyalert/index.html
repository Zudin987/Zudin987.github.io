BPSR Ready Alert

Ready/queue alerts with an optional view-only floating BPSR chat overlay.

Download latest EXE

Latest release: checking…

Use

  1. Make sure Npcap is installed.
  2. Open BPSR Ready Alert.
  3. Select Resonance Logs CN or the correct network adapter if auto-detection misses it.
  4. Leave it running in the system tray.
  5. Enable Chat Overlay only if you want the chat window.

What it does

  • Matchmaking / Ready Check sound alerts and optional desktop notifications.
  • Optional chat overlay with tabs, filters, keyword sounds, opacity, click-through and Always on Top.
  • Simple filters such as serum | food | raid and boss AND hard.
  • Alerts + chat share one Npcap capture.

Notes

Npcap is required and is not bundled. ReadyAlert can run beside Resonance Logs CN and can auto-launch it.

It does not inject into BPSR, replace game files, send chat, or automate gameplay.
