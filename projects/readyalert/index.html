Quick start

  1. Make sure Npcap is installed.
  2. Open BPSR Ready Alert.
  3. Select Resonance Logs CN or the correct network adapter if automatic detection is wrong.
  4. Leave the app running in the system tray.

Notes

  • Alerts can be enabled or disabled individually.
  • Alert volume is controlled inside the app.
  • Only one capture adapter is used at a time.
  • The app uses Npcap capture. It does not inject into or replace BPSR files.
