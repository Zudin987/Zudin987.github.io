Quick start

From download to playing

  1. Download and open the EXEChoose Lite for normal MIDI playback. Choose Studio only if you want its extra conversion tools.
  2. Choose Instrument → Category → SongLeave speed at 100% unless you intentionally want a different tempo.
  3. Run Song CheckThe app reports remapped, skipped, filtered and playable notes before playback.
  4. Press Play and return to BPSRPlayback starts after the countdown. Press F10 at any time for the global emergency stop.

What it does

Built around BPSR instrument limits

  • Local .mid / .midi playback that works offline.
  • Online Sequencer search, URL/ID loading, bookmarks and Save to Local.
  • Automatic note fitting for BPSR instrument ranges.
  • Song Check, live waterfall, adjustable speed and pause/resume.
  • Foreground-process lock so held keys release if another app steals focus.
Recommended input: leave Win32 scan code selected if playback already works. The app does not modify BPSR game files.

Lite or Studio?

Use the smaller edition unless you need conversion

Lite

Best if you already have MIDI files or use Online Sequencer. This is the normal lightweight build.

Studio — Experimental Beta

Adds public YouTube/audio search and conversion. Clean piano, guitar, bass, instrumental or melody-focused sources usually convert better than dense full mixes.

Content note: only process audio or media you are permitted to use. Studio does not need your Google/YouTube login or browser cookies.
