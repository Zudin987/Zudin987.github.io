BPSR MIDI Lite / Studio

Play MIDI through BPSR instruments. Studio also adds experimental YouTube/audio → MIDI.

Download MIDI Lite Download Studio beta

Latest release: checking…

Use

  1. Open the EXE.
  2. Choose the instrument, category and song.
  3. Use Song Check if you want to see remapped/skipped notes.
  4. Press Play and return to BPSR before the countdown ends.

Press F10 any time to stop and release held keys.

Which one?

Lite: local MIDI + Online Sequencer. This is the normal lightweight build.

Studio: Lite features + experimental audio/YouTube-to-MIDI. It is much larger.

No Python install is needed. The app does not modify BPSR game files.
