BPSR MIDI Lite / Studio

Play local MIDI files or Online Sequencer songs through BPSR instruments. Studio adds experimental audio-to-MIDI conversion.

Quick start

  1. Open the EXE.
  2. Choose the instrument and song.
  3. Run Song Check if you want to see remapped or skipped notes first.
  4. Press Play, return to BPSR, and use F10 if you need an emergency stop.

Which version?

MIDI Lite is the normal lightweight build for MIDI and Online Sequencer playback.

Studio is much larger and only needed if you want the experimental audio or YouTube-to-MIDI tools.

Notes

  • Portable Windows app. No Python installation is required.
  • Supports BPSR Keyboard/Piano, Electric Guitar and Electric Bass.
  • The app fits notes to the supported BPSR instrument range.
  • It does not modify BPSR game files.
