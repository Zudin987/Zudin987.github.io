BPSR Custom PFP Lite

Prepare a custom Blue Protocol: Star Resonance portrait or card with built-in cropping, numbered instructions and backup and restore controls.

Download latest release Read documentation
View source on GitHubReport an issue

What it does

  • Square portrait and card workflows with image cropping and repositioning.
  • Game-folder and picture-slot detection with manual fallbacks.
  • Install-specific backups and a guided restore step after capture.

Quick start

  1. Download and extract the Windows ZIP, then open the app and select your BPSR folder.
  2. Choose and crop your image. Follow the app’s numbered steps to save the portrait or card in BPSR.
  3. Restore the original BPSR file when you finish. Keep the backup until the app confirms restoration.

Further reading

  • Changes and recovery improvements

Requirements

  • Windows with BPSR installed
  • An image for your portrait or card
  • Write access to the game installation

Before you use it

This method temporarily changes a BPSR client file. It is unofficial and is not guaranteed ban-safe.

If the game updates while a custom file is active, close BPSR and use the launcher’s Verify or Repair feature instead of forcing an old backup.
