BPSR CustomPFP Lite

Guided custom BPSR profile picture/card workflow.

This temporarily modifies a BPSR client file. It is unofficial and is not guaranteed ban-safe.
Download latest ZIP

Latest release: checking…

Use

  1. Find your BPSR folder.
  2. Choose and crop your picture.
  3. Open Guild Photo Booth and follow the numbered checks in the app.
  4. Apply the temporary image and save the portrait/card in BPSR.
  5. Restore the original BPSR file when finished.

If something changed

If BPSR updates while the custom file is active, do not force an old backup. Close the game and use the launcher/Steam Verify or Repair, then try again.

Your selected image and backups stay on your PC.
