BPSR Custom PFP Lite

Prepare a custom Blue Protocol: Star Resonance portrait or card with cropping, numbered instructions, backup and restore controls.

Download latest releaseRead documentation
View source on GitHub

What it does

  • Square portrait and card workflows with image cropping and repositioning.
  • Game-folder and picture-slot detection, with manual fallbacks.
  • Install-specific backups and a guided restoration step after capture.

Quick start

  1. Download and extract the Windows ZIP, then open the app and select your BPSR folder.
  2. Choose and crop your image. Follow the numbered steps to save the portrait or card in BPSR.
  3. Restore the original game file when finished. Keep the backup until restoration is confirmed.

Further reading

  • Changes and recovery improvements

Requirements

  • Windows with BPSR installed
  • An image for your portrait or card
  • Write access to the game installation

Before you use it

This tool temporarily modifies a game client file. It is unofficial and not guaranteed ban-safe.

If the game updates with a custom file active, close BPSR and use the launcher's Verify or Repair option instead of forcing an old backup.
