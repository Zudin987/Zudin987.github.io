Portable Stream Kit

A portable Windows launcher that brings game capture, frames and optional avatars into one setup. Share through Discord or stream with OBS.

Download latest release Read documentation
View source on GitHubReport an issue

What it does

  • Choose a game, frame, avatar and destination, then reuse your choices with Quick Launch.
  • Share the OBS Program Projector in Discord or connect a Twitch account in OBS.
  • Use a talking PNG, connect VTube Studio for Live2D, or stream without an avatar.

Quick start

  1. Download StreamKit-win-x64.zip and extract the entire ZIP to a folder you can keep.
  2. Open your game, run BPSRStreamKit.exe and choose your game, avatar, frame and destination.
  3. Press the main start button. For Discord, share the OBS Program Projector window.

Requirements

  • 64-bit Windows
  • The complete portable release folder
  • VTube Studio only if you want Live2D
  • TikTok LIVE/stream-key access only for TikTok streaming

Before you use it

Keep OBS and its bundled plugins together. Update the bundle through a newer Stream Kit release.

VTube Studio is not included. Twitch sign-in happens in OBS; TikTok access depends on your account.
