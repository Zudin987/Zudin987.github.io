Quick start

From ZIP to stream layout

  1. Extract the complete release ZIPKeep the bundle together so the launcher can find its portable OBS, plugins, templates and assets.
  2. Run BPSRStreamKit.exeOpen your game first, then choose the game, avatar mode, frame and destination.
  3. Press the main start buttonStreamKit prepares the matching OBS scene/output path for Discord-only or public streaming.
  4. Use Quick Launch next timeAfter a successful start, your selected game, avatar, frame and destination are remembered.

Destinations

Use one setup for different stream paths

Discord only

Share the clean OBS Program Projector window with sound. OBS Mic/Aux stays muted so your normal Discord microphone remains your voice path and is not doubled.

Discord + Twitch

Discord still receives the clean projector view while Twitch receives the normal 1920×1080 public stream output.

Optional TikTok

When your TikTok account has LIVE/stream-key access, StreamKit can prepare a vertical Aitum output. The tool cannot grant TikTok LIVE or stream-key access.

Avatar & audio privacy

Choose how much streaming stack you want

  • Full VTuber mode uses VTube Studio + Spout2.
  • Simple Talking Avatar uses the bundled PNG avatar workflow.
  • No Avatar captures only the selected game and frame.
  • The selected game is captured with its own audio instead of a general desktop loopback.
  • Public-stream microphone audio receives OBS RNNoise suppression.
Credentials stay local: Twitch/TikTok credentials, OAuth data, Aitum outputs and the generated OBS WebSocket password remain in the extracted StreamKit folder and are excluded from source control.

Bundle maintenance

Treat portable OBS + plugins as one tested package

The portable bundle uses pinned versions of OBS Studio and the plugins StreamKit expects. Update through a newer tested StreamKit release rather than letting the portable OBS copy independently drift away from the tested combination.
