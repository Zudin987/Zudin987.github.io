Portable Stream Kit

Portable game capture and streaming setup for Discord, Twitch and optional TikTok.

Download latest ZIP

Latest release: checking…

Use

  1. Extract the whole ZIP.
  2. Open the game you want to capture.
  3. Run BPSRStreamKit.exe.
  4. Choose the game, avatar, frame and destination.
  5. Press the main start button. Use Quick Launch next time.

Supports

  • Discord sharing through the OBS Program Projector.
  • Twitch streaming.
  • Optional TikTok output if your account already has LIVE/stream-key access.
  • Live2D/VTube Studio, simple talking PNG, or no avatar.

Notes

VTube Studio is not bundled. Keep the portable OBS/plugin bundle together and update it through a newer StreamKit release.

Streaming credentials and generated local settings stay in your extracted StreamKit folder.
