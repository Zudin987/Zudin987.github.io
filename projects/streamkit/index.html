Quick start

  1. Extract the complete ZIP.
  2. Open the game you want to capture.
  3. Run BPSRStreamKit.exe and choose the game, avatar, frame and destination.
  4. Start the setup. Use Quick Launch next time if you want the same choices again.

What it supports

  • Discord-only sharing through the OBS Program Projector.
  • Twitch streaming.
  • Optional TikTok output when your account already has LIVE or stream-key access.
  • Live2D VTuber, simple talking PNG, or no avatar.
  • Portable OBS and the tested plugin bundle are kept together.

Notes

Extract the whole archive before launching it. Update the portable OBS bundle through a newer StreamKit release instead of separately updating individual bundled components.

Streaming credentials and generated local settings stay in the extracted StreamKit folder.
