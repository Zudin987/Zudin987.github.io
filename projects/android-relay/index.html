BPSR Android DPSMeter Relay

Play BPSR on Android while a compatible DPS meter captures the relayed traffic on your PC.

Download ZIP GitHub release

Latest release: checking…

First setup

  1. Download and extract the latest ZIP, then run BPSR Relay Manager.
  2. Select the PC network address connected to the same router as your phone.
  3. Prepare Relay → Allow Firewall → Start Phone Setup.
  4. Scan/import the QR profile in Android SFA and route BPSR only.
  5. Start Relay on PC, start SFA on the phone, then open BPSR.
  6. Set your compatible DPS meter capture/process target to StarSEA.

Daily use

PC Start Relay → Android Start SFA → Open BPSR

You normally only need the full phone setup again if the PC LAN IP changes, the relay is upgraded, or the manager asks you to repair it.

Network note

Use this on a trusted home/private LAN only. Do not port-forward relay port 10808. The phone → PC SOCKS5 hop is authenticated but not encrypted.

Use StarSEA as the DPS capture target, not BPSRMobileFront.
