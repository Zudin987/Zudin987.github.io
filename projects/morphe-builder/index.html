builder-for-morphe

A personal fork of nvbangg/builder-for-morphe. Configure app builds, run the workflow and review the resulting APKs and build notes on GitHub.

View published builds Read documentation
View source on GitHubView pull requests

What it does

  • Configure applications and patch sources in config.toml.
  • Run builds through GitHub Actions or follow the local build guide.
  • Review release assets and build notes for each app.

Quick start

  1. Read the repository’s setup guide and configure the applications in config.toml.
  2. Run the CI workflow in your fork and review the build output.
  3. Set ALLOW_PUBLIC_APK_RELEASES=false to keep generated releases as drafts.

Further reading

  • Setup and configuration guide

Requirements

  • A GitHub fork with Actions enabled for your own builds
  • App and patch configuration
  • For local builds: Git, Python, uv and Java; see the setup guide

Before you use it

APK availability varies by app and build. This is a community fork, not an official Morphe distribution.

Only publish third-party APKs when you have the right to redistribute them. Upstream credits and GPLv3 terms remain in the repository.

Issue tracking is disabled for this repository. Proposed fixes can be submitted through GitHub pull requests.
