Before you download

Common questions

The site now sends you to a tool page first, so you only see instructions relevant to that app.

Where do the downloads come from?

From the matching Zudin987 GitHub repository. When a stable release filename allows it, the download button points directly to GitHub's latest release asset. Otherwise it opens the latest release page so you can choose the correct file.

Why can Windows warn about an EXE?

Small community apps can trigger reputation-based warnings even when downloaded from GitHub. Use only the links on this site or the matching repository, and check the release notes or SHA-256 file when the project provides one.

Are these official BPSR tools?

No. The BPSR projects on this site are unofficial community utilities and are not affiliated with the game's developers or publishers.

Do I need the GitHub “Source code” ZIP?

Usually no. Normal users should use the labelled EXE, APK or release ZIP. “Source code” downloads are mainly for developers unless a project guide says otherwise.
